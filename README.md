# The Arabic Vet Atlas | الأطلس البيطري العربي
Independent Arabic-first, free educational 3D veterinary atlas. First species: dog. Phone-first development via GitHub and cloud agents.
## Status
Foundation prototype only. The asset catalog starts empty intentionally; no clinical or anatomical claims are made by the viewer. No imported third-party code or assets yet.
## Run
Node 22+, npm install, npm run dev. npm run check validates the catalog and TypeScript; npm run build builds dist. npm test runs catalog tests.
