---
name: headless-geometry
description: Process authorized CT-derived or scanned veterinary geometry reproducibly in a cloud sandbox.
---
Preserve raw assets and source hashes outside Git. Inspect actual units, coordinate frame, laterality, mesh count and topology; never guess scale. Use isolated pinned Blender headless with --python-exit-code 1 and explicit arguments, disable auto-run. Export GLB with persistent Three.js-safe node IDs (`^[A-Za-z0-9_-]{1,128}$` — no dots, spaces, or `.001` Blender suffixes that Three.js sanitizes at runtime), source-to-output transforms, logs and checksums. Compare before/after dimensions, landmarks and six views; do not decimate until anatomical features pass review. When running glTF-Transform, never use default mesh-joining or flattening (`--join false --flatten false`) because it silently destroys named anatomical nodes; verify node survival after optimization. Keep GLBs within mobile size/complexity budgets (<= 15 MiB, <= 1.5M vertices) and run Khronos glTF Validator before release; test decoder support before enabling Meshopt/Draco/KTX2. Do not merge unrelated specimens.
