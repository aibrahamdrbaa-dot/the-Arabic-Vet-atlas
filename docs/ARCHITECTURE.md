# ADR-001 — foundation (revised 2026-11-26)
Independent static Vite + React + TypeScript + direct Three.js. Keep this until measured need to move to R3F or other renderer. No backend, AI runtime, database or accounts initially. JSON versioned data contract separates specimen, concept and asset; see DATA_CONTRACT.md. Asset binaries referenced by local paths and hashes; draft data private/outside public, no public raw medical files. Stable IDs and mappings survive translation and geometry revisions.
Viewer lazy loaded, demand rendering, abortable fetch, bounded DPR, context handling and cleanup; no remote GLB resources. Initial catalog empty. Future selection, layers, clipping, evidence notes and offline packs only after real specimen pilot. Use separate specimen scenes. GitHub Actions CI, PR workflow, lockfile required before pilot, no direct edits to main. Hosting target determined after testing asset sizes and traffic; no deployment yet.
Mobile acceptance: no horizontal scroll at 360px, usable touch and keyboard, non-WebGL alternative, measure actual phone FPS, memory, load time and transfer. Do not promise performance without measurements. Prioritize anatomy accuracy before appearance.
