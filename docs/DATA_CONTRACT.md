# Data contract v1
Three independent records: specimen (physical sample), structure (species-specific concept with stable local ID and names), asset (one binary with provenance, transformation, and node-to-structure bindings). Never key identity by translated label or mesh filename. Model units metres; retain source units and transforms in audit. NAV is the terminology authority; optional Uberon mappings are cross-species links, never automatic equivalence. Add anatomy facts as referenced claims; unknown is not a guess. Separate scientific and rights approvals; reviewer, date and evidence links required. CI enforces structure, file integrity, declared nodes, and no orphan files in public/models; cannot certify actual human approval or anatomy. Keep drafts outside public (do not upload raw scans or sensitive metadata to public repo). Release only separately reviewed content; no procedural/composite/path geometry in first release. Future schema migration: explicit schemaVersion with backward compatibility or migration script. Use content hashes for source and derivative separately. Current GLB check is preliminary, Khronos validator and external resource security review required before pilot; compression decoders deliberately deferred. Keep data catalog empty until pilot.
