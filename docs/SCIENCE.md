# Scientific and asset governance
Use Nomina Anatomica Veterinaria (NAV) for terminology; cite anatomy references with edition/page or DOI. Each structure: Arabic/English/Latin names, ID, species, specimen, system, region, laterality, source, review status; muscles later require origin/insertion/innervation/blood supply/function. Unknown fields must be explicitly unknown, not invented.
Asset records distinguish segmented CT/MRI, surface scan, 1D path, procedural and composite. Paths are not muscle volumes. Separate specimens/breeds; keep original geometry and transforms traceable. Do not label a model verified solely because the source is academic. Expert review required to promote from draft. No synthetic anatomy as evidence.
Licenses: validate actual asset license (not just paper or repository license), author, source URL, permitted modifications/redistribution, attribution, NC/SA/ND conditions. NC is not open-source-compatible in the strict sense; keep separate asset licensing. No ND modified assets. If uncertain, quarantine outside public repo. MIT covers original code only. Do not assume free access implies redistribution rights. Track corrections and citations.
