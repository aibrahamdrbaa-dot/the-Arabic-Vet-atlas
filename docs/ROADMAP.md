# Roadmap (no duration or coverage promises)
P0 foundation: independent repo, docs, empty catalog, minimal viewer, tests and CI. Gemini validates lockfile/build/CI; no assets yet.
P1 first evidence-backed pilot: audit 1 source, fetch only permitted files in cloud, record license and SHA256, normalize and optimize GLB, validate named meshes, preview in browser, review anatomy. Publish preview only after review.
P2 skeleton and specimen-based hindlimb: preserve coherent geometry, localized structure data and source links; add selection, isolation, search and glossary. Confirm mobile performance.
P3 education: quizzes, notes stored locally, Arabic/English/Latin search, offline optional.
P4 vascular, nerves, organs, other species only when suitable evidence and reviewed assets exist. Do not fill gaps with fabricated meshes.
Acceptance for each PR: scope, evidence, license, tests, screenshots/preview when UI changes, limitations, review and rollback notes.
